# ADR-0004: دفتر کل تغییرناپذیر و ابطال به‌جای حذف

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
قابل پیگیری بودن عملیات مالی و صحت گزارش‌ها.

## تصمیم
جدول‌های `transactions` و `ledger_entries` فقط درج می‌شوند. ابطال = علامت `voided` + سند `reversal` قرینه + audit. موجودی همیشه از جمع ردیف‌ها محاسبه می‌شود.

## گزینه‌های ردشده
ستون موجودی ذخیره‌شده با به‌روزرسانی مستقیم (سریع ولی مستعد ناسازگاری)؛ حذف نرم ساده (اثر روی موجودی مبهم)

## پیامدها
کوئری موجودی هزینه دارد (ایندکس + در صورت نیاز کش یا Materialized View پس از اندازه‌گیری).
