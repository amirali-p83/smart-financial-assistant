# ADR-0010: جداسازی کاربران: فیلتر برنامه + کلید خارجی مرکب + RLS

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
نشت داده بین کاربران بحرانی‌ترین ریسک محصول است.

## تصمیم
(۱) همه Repositoryها `user_id` می‌گیرند. (۲) کلیدهای خارجی مرکب `(user_id, id)`. (۳) PostgreSQL Row Level Security با `SET LOCAL app.user_id` در هر تراکنش. (۴) نقش اپلیکیشن بدون `BYPASSRLS`؛ worker با نقش جدا و محدود. (۵) تست نفوذ بین کاربران.

## گزینه‌های ردشده
فقط فیلتر برنامه (یک فراموشی = نشت)؛ دیتابیس جدا برای هر کاربر (هزینه عملیاتی)

## پیامدها
پیچیدگی بیشتر در تست و Celery. اگر در spike فاز ۲ مشکل جدی دیده شد، بازبینی می‌شود.
