# ADR-0001: ساختار مخزن: Monorepo

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
بک‌اند، فرانت و مستندات باید همگام تغییر کنند (مثلاً تایپ‌های تولیدشده از OpenAPI) و پروژه توسط یک تیم کوچک نگهداری می‌شود.

## تصمیم
یک مخزن شامل `backend/`، `frontend/`، `docs/`، `deploy/`.

## گزینه‌های ردشده
چند مخزن جدا (هماهنگی نسخه‌ها سخت‌تر)

## پیامدها
یک PR می‌تواند API و UI را با هم تغییر دهد؛ CI باید مسیرها را جدا اجرا کند.
