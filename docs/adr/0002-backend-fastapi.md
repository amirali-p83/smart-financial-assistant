# ADR-0002: بک‌اند: Python 3.12 + FastAPI

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
نیاز به اعتبارسنجی دقیق ورودی، مستندات OpenAPI خودکار، عدد صحیح بزرگ بدون محدودیت و اکوسیستم قوی برای هوش مصنوعی و گفتار.

## تصمیم
Python 3.12، FastAPI، Pydantic v2، SQLAlchemy 2.0 (async یا sync با تصمیم در فاز ۱ بر اساس سادگی تست)، Alembic، uv برای وابستگی‌ها.

## گزینه‌های ردشده
NestJS/TypeScript (یک زبان برای کل پروژه، اما اکوسیستم گفتار/LLM ضعیف‌تر و کار با اعداد بزرگ پرزحمت‌تر)؛ Django (قوی ولی سنگین‌تر برای API-محور با Schema صریح)

## پیامدها
ایمنی نوع با mypy و Pydantic؛ نیاز به دو زبان (Python و TypeScript) در پروژه.
