# ADR-0003: دیتابیس PostgreSQL و مبلغ به صورت عدد صحیح ریال

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
داده مالی به تراکنش ACID، قیود دقیق، قفل ردیف و ایندکس جزئی نیاز دارد. خطای اعشار در پول غیرقابل قبول است.

## تصمیم
PostgreSQL 16. مبلغ `BIGINT` ریال با CHECK (۱…10^13). تومان فقط نمایشی.

## گزینه‌های ردشده
SQLite (همزمانی و قفل ضعیف)، MySQL (CHECK/ایندکس جزئی محدودتر)، `NUMERIC` (ممکن ولی بی‌دلیل پیچیده؛ ریال عدد صحیح است)

## پیامدها
محدودیت 10^13 ریال برای هر مبلغ (۱۰^۱۲ تومان) و تبدیل‌های واحد باید فقط در یک جا باشد (`Money`).
