# ADR-0009: تشخیص گفتار فارسی: faster-whisper

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
Web Speech API وابسته به مرورگر و سرویس خارجی و برای فارسی ناپایدار است.

## تصمیم
ضبط با `MediaRecorder` و ارسال به بک‌اند؛ `faster-whisper` با اندازه مدل قابل تنظیم؛ متن قابل ویرایش پیش از ارسال به دستیار؛ فایل پس از تبدیل حذف می‌شود.

## گزینه‌های ردشده
Web Speech API (بدون هزینه سرور ولی ناهمگون)؛ سرویس ابری STT (هزینه و ارسال صدا به بیرون)

## پیامدها
مصرف CPU/RAM؛ اندازه مدل با اندازه‌گیری در فاز ۵ تعیین می‌شود؛ کیفیت پیش از آن ادعا نمی‌شود.
