# ADR-0012: استقرار: Docker Compose + Caddy + GitHub Actions

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
هزینه کم، سادگی نگهداری و قابلیت بازتولید.

## تصمیم
VPS با Docker Compose؛ Caddy برای HTTPS خودکار؛ ایمیج‌ها در GHCR؛ استقرار با SSH از GitHub Actions؛ اسرار در GitHub Secrets و `.env` سرور؛ بکاپ `pg_dump` رمزگذاری‌شده.

## گزینه‌های ردشده
Kubernetes (بیش از نیاز)؛ PaaS (هزینه و محدودیت‌های منطقه‌ای)

## پیامدها
مقیاس‌پذیری افقی محدود است؛ برای نسخه ۱ کافی است.
