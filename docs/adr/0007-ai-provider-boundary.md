# ADR-0007: لایه هوش مصنوعی: پیشنهاد، نه تصمیم

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
مدل زبانی ممکن است اشتباه کند یا تحت تأثیر ورودی مخرب قرار بگیرد. دسترسی سرور به سرویس خارجی هم تضمین‌شده نیست.

## تصمیم
اینترفیس `LLMProvider` قابل تعویض. خروجی ساخت‌یافته با JSON Schema. مبلغ/تاریخ را پارسر قطعی بک‌اند تبدیل می‌کند. ابزارهای مدل فقط‌خواندنی‌اند. اجرا فقط پس از تأیید کاربر. `FakeLLMProvider` برای CI.

## گزینه‌های ردشده
اجرای مستقیم خروجی مدل (خطرناک)؛ اتکا به مدل برای محاسبه عدد (غیرقابل اعتماد)

## پیامدها
کیفیت فهم فرمان به کیفیت مدل و پارسرها بستگی دارد؛ در فاز ۵ اندازه‌گیری می‌شود.
