# ADR-0005: مدیریت تاریخ شمسی

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
کاربر شمسی فکر می‌کند ولی مرتب‌سازی، بازه و محاسبه سررسید به تاریخ میلادی بهتر انجام می‌شود.

## تصمیم
ذخیره `DATE` میلادی. API میلادی ISO می‌گیرد و هر دو فرم را برمی‌گرداند. بک‌اند: `jdatetime`. فرانت: تقویم شمسی `react-multi-date-picker`. تست تطبیق دو سمت بازه ۱۳۰۰–۱۵۰۰. منطقه زمانی `Asia/Tehran` برای «امروز».

## گزینه‌های ردشده
ذخیره رشته شمسی (مرتب‌سازی و محاسبه دشوار)

## پیامدها
ریسک ناسازگاری بین کتابخانه فرانت و بک‌اند با تست کاهش می‌یابد.
