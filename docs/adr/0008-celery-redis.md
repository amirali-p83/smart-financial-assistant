# ADR-0008: وظایف پس‌زمینه: Celery + Redis

- **وضعیت:** پیشنهادشده (پس از تأیید صاحب محصول: پذیرفته‌شده)
- **تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه
یادآوری سررسید باید مستقل از مرورگر باشد و retry و ثبت وضعیت داشته باشد.

## تصمیم
Celery worker و beat جدا؛ Redis به‌عنوان broker و rate limit. وظایف ایدمپوتنت‌اند و تکرار نشدن با `UNIQUE` دیتابیس تضمین می‌شود.

## گزینه‌های ردشده
APScheduler داخل API (با چند نمونه تکراری اجرا می‌شود)؛ cron + اسکریپت (retry و مشاهده‌پذیری ضعیف)

## پیامدها
یک سرویس اضافه (Redis) و نیاز به اجرای دقیقاً یک beat.
