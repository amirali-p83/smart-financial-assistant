# ۶. مدل تهدید و کنترل‌های امنیتی

## ۶.۱ دارایی‌ها
۱. داده مالی کاربران (محرمانگی و صحت) ۲. اعتبار ورود و توکن‌ها ۳. صحت دفتر کل ۴. کلیدهای API (LLM) و اسرار سرور ۵. صدای ضبط‌شده کاربر ۶. دسترس‌پذیری یادآوری‌ها

## ۶.۲ مرزهای اعتماد
مرورگر ⟷ API (غیرقابل اعتماد) | API ⟷ LLM خارجی (غیرقابل اعتماد، خروجی باید اعتبارسنجی شود) | API ⟷ دیتابیس (قابل اعتماد، با دسترسی حداقلی)

## ۶.۴ حریم خصوصی
- حداقل داده: فقط ایمیل، نام و داده مالی لازم.
- صدا: پس از تبدیل به متن **حذف** می‌شود و ذخیره نمی‌شود.
- متن فرمان‌ها ذخیره می‌شود (برای پیش‌نمایش/تأیید) و قابل حذف همراه حساب کاربر است.
- حذف حساب کاربر: در فاز ۷ مسیر و سیاست مشخص می‌شود (تعارض با «حذف ممنوع» برای دفتر کل فقط در سطح حذف کامل حساب است).

## ۶.۵ آنچه در این فاز ادعا نمی‌شود
هیچ‌کدام از کنترل‌ها هنوز پیاده‌سازی یا آزمایش نشده‌اند. این سند فقط **الزامات** است؛ وضعیت هر مورد در فاز مربوط گزارش می‌شود.
