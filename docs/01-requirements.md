# ۱. نیازمندی‌ها، محدوده و فرضیات

## ۱.۱ کاربر هدف
صاحب مغازه یا کسب‌وکار کوچک بدون حسابدار. زبان محصول فارسی، راست‌چین، با تاریخ شمسی و پول به تومان (ذخیره‌سازی به ریال).

## ۱.۴ خارج از محدوده نسخه ۱.۰
- اتصال به درگاه بانکی یا دریافت خودکار تراکنش بانکی
- موجودی انبار و فاکتور فروش
- چندکاربره در یک کسب‌وکار (نقش‌ها). ساختار داده طوری طراحی می‌شود که اضافه کردنش بعداً سخت نباشد.
- پیامک و ایمیل برای یادآوری (فقط اعلان درون‌برنامه‌ای؛ اینترفیس کانال‌ها آماده می‌شود)
- اپلیکیشن بومی موبایل (فقط PWA-ready؛ PWA کامل در نسخه‌های بعدی)

## ۱.۵ فرضیات
1. یک کاربر = یک کسب‌وکار = یک ارز (ریال/تومان).
2. منطقه زمانی ثابت `Asia/Tehran`. تاریخ‌ها در سطح «روز» هستند (نه ساعت) مگر زمان ایجاد رکورد.
3. ثبت‌نام با ایمیل و رمز عبور. ورود با OTP موبایل در نسخه‌های بعد.
4. دسترسی سرور به API هوش مصنوعی خارجی باید در فاز ۵ تأیید شود؛ در غیر این صورت از مدل قابل‌میزبانی‌شده یا حالت محدود استفاده می‌شود (ADR-0007).
5. کیفیت تشخیص گفتار فارسی قبل از فاز ۵ ادعا نمی‌شود و در همان فاز اندازه‌گیری می‌شود.
6. اعداد ماکاپ فقط برای داده نمونه (seed) هستند و در محصول از دیتابیس خوانده می‌شوند.
